コイマチ サポート・使い方

全国の自治体・公的機関や街コン運営会社が主催する婚活・恋活イベントをまとめて探せるアプリです。

基本の使い方(3ステップ)

1. イベントを探す
地域やカテゴリで絞り込んで、開催予定のイベントを一覧で確認できます。
2. 気になるイベントを保存する
ハートを押すと保存されます。あとから「保存したイベント」でまとめて見返せます。
3. 申し込む
申し込みは各イベント主催者のページで行います。アプリ内でのお申し込み受付は行っていません。

よくある質問

アプリ内でマッチングはできますか

できません。コイマチはイベント情報をまとめて掲載する情報アプリです。ユーザー同士がやりとりする機能はありません。

ログインしないと使えませんか

ログインなしでイベントの閲覧ができます。イベントの保存やレビュー投稿にはログインが必要です。

掲載されているイベントの申し込みはどこからですか

各イベントの詳細画面から、主催者のページへ移動してお申し込みください。参加費・キャンセル規定などの条件は主催者の定めるものに従います。

掲載情報が古い・間違っている

お手数ですが下記までご連絡ください。イベント情報は主催者の公開情報をもとに掲載していますが、内容が変更されている場合があります。最新の情報は必ず主催者のページでご確認ください。

位置情報は何に使われますか

お近くのイベントを表示するために使用します。許可しない場合でも、地域を選んでイベントを探せます。詳しくはプライバシーポリシーをご覧ください。

掲載してほしいイベントがあります

主催者の方からのご相談も受け付けています。下記までご連絡ください。

Koimachi — Support

A directory app for matchmaking and singles events held across Japan by local governments, public bodies and event organisers. Content is in Japanese.

Getting started

1. Find events
Filter by region and category to see upcoming events.
2. Save the ones you like
Tap the heart to save an event and find it again later.
3. Apply
Applications are handled on each organiser's own page. Koimachi does not take bookings.

Frequently asked questions

Is there a matching or messaging feature?

No. Koimachi lists events; it does not connect users to each other and has no messaging.

Do I need to sign in?

You can browse events without signing in. Signing in is required to save events and post reviews.

An event listing looks out of date

Please let us know at the address below. Listings are based on information published by the organisers and may change; always check the organiser's page for the latest details.
